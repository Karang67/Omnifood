Basic Knowledge of HTML & CSS Components
1. What is HTML?
HTML (HyperText Markup Language) is the standard language used to structure web pages. It consists of elements (tags) that define the different parts of a webpage (text, images, links, forms, etc.).

2. What is CSS?
CSS (Cascading Style Sheets) is used to style HTML elements. It controls colors, fonts, layouts, spacing, and responsiveness.

3. Basic HTML Components
a) <div> (Division)
✅ Used for:

Grouping multiple elements.

Applying styles to a section of the page.

Creating layout structures.

💡 Example:

html
Copy
Edit
<div class="container">
    <h1>Welcome</h1>
    <p>This is a paragraph inside a div.</p>
</div>
👉 Without CSS, <div> has no visual effect—it just groups content.

b) <span> (Inline Container)
✅ Used for:

Styling small parts of text inside another element.

💡 Example:

html
Copy
Edit
<p>This is a <span style="color: red;">red</span> word.</p>
👉 Unlike <div>, <span> does not create a block—it stays inline.

c) Headings (<h1> to <h6>)
✅ Used for:

Creating headings of different sizes.

<h1> is the largest, <h6> is the smallest.

💡 Example:

html
Copy
Edit
<h1>Main Title</h1>
<h2>Subheading</h2>
<h3>Smaller Heading</h3>
d) Paragraph (<p>)
✅ Used for:

Displaying text content in paragraphs.

💡 Example:

html
Copy
Edit
<p>This is a paragraph with some text.</p>
e) Anchor (<a> - Links)
✅ Used for:

Creating hyperlinks.

💡 Example:

html
Copy
Edit
<a href="https://google.com">Go to Google</a>
href → Defines the link destination.

f) Image (<img>)
✅ Used for:

Displaying images.

💡 Example:

html
Copy
Edit
<img src="image.jpg" alt="Description of the image">
src → Specifies the image path.

alt → Alternative text for accessibility.

g) List (<ul>, <ol>, <li>)
✅ Used for:

Creating unordered lists (<ul>) and ordered lists (<ol>).

💡 Example:

html
Copy
Edit
<ul>
    <li>Apple</li>
    <li>Banana</li>
    <li>Orange</li>
</ul>

<ol>
    <li>Step 1</li>
    <li>Step 2</li>
</ol>
h) Table (<table>)
✅ Used for:

Displaying data in a tabular format.

💡 Example:

html
Copy
Edit
<table border="1">
    <tr>
        <th>Name</th>
        <th>Age</th>
    </tr>
    <tr>
        <td>John</td>
        <td>25</td>
    </tr>
</table>
<th> → Table headers.

<td> → Table data.

<tr> → Table row.

i) Form Elements (<form>, <input>, <button>)
✅ Used for:

Taking user input.

💡 Example:

html
Copy
Edit
<form action="/submit" method="POST">
    <input type="text" placeholder="Enter your name">
    <button type="submit">Submit</button>
</form>
4. Basic CSS Properties
a) Selectors
Element Selector:

css
Copy
Edit
p {
    color: blue;
}
(Applies to all <p> elements.)

Class Selector (.)

css
Copy
Edit
.box {
    background-color: yellow;
}
(Applies to elements with class="box".)

ID Selector (#)

css
Copy
Edit
#header {
    font-size: 24px;
}
(Applies to an element with id="header".)

b) Box Model
Every HTML element is a box with:

Margin (Outer space)

Border (Outline)

Padding (Inner space)

Content (Actual text/image)

💡 Example:

css
Copy
Edit
.box {
    width: 200px;
    padding: 10px;
    border: 2px solid black;
    margin: 20px;
}
c) Layout Techniques
1) Flexbox
✅ Used for:

Aligning items in a row or column.

💡 Example:

css
Copy
Edit
.container {
    display: flex;
    justify-content: center;
    align-items: center;
}
2) Grid
✅ Used for:

Creating complex layouts.

💡 Example:

css
Copy
Edit
.container {
    display: grid;
    grid-template-columns: 1fr 2fr;
}
Conclusion
HTML Recap
<div> → Groups content.

<span> → Styles inline text.

<p> → Paragraphs.

<a> → Links.

<img> → Images.

<ul> / <ol> → Lists.

<table> → Tables.

<form> → Forms.

CSS Recap
Use selectors (.class, #id, element).

Box model (margin, padding, border).

Flexbox/Grid for layouts.
