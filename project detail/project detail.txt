Language and Technologies Used
JavaScript (ES6+ Syntax) – The programming language used in this code.

Node.js – A runtime environment that allows JavaScript to run outside the browser.

Express.js – A lightweight web framework for Node.js used to build web applications.

MongoDB – A NoSQL database used for storing customer data.

Mongoose – An ODM (Object Data Modeling) library that simplifies MongoDB interactions.

Body-Parser (Deprecated) – Middleware used to parse incoming request bodies.

Path Module – A built-in module in Node.js for working with file paths.

ES Module (import/export) – A modern way of handling modules in JavaScript.

2. Handling __dirname in ES Modules
js
Copy
Edit
const __filename = fileURLToPath(import.meta.url);
const __dirname = path.dirname(__filename);
Why?
In CommonJS (require), we have __dirname. But in ES Modules (import/export), __dirname is not available.
So, we manually derive it using fileURLToPath.

4. Connecting to MongoDB
js
Copy
Edit
async function connectDB() {
    try {
        await mongoose.connect("mongodb://127.0.0.1:27017/customerData", {
            useNewUrlParser: true,
            useUnifiedTopology: true,
        });
        console.log("Connected to MongoDB successfully!");
    } catch (error) {
        console.error("Error connecting to MongoDB:", error);
    }
}
connectDB();
async function → Handles MongoDB connection asynchronously.

mongoose.connect() → Connects to the MongoDB database (customerData).

Options:

useNewUrlParser: true → Prevents deprecated URL parser warnings.

useUnifiedTopology: true → Enables the new MongoDB driver topology engine.

If the connection fails, an error is logged.

9. Handling Form Submission (POST /contact)
js
Copy
Edit
app.post("/contact", async (req, res) => {
    const { name, email, phone, address, desc } = req.body;
    const contactData = new Contact({ name, email, phone, address, desc });
    try {
        await contactData.save();
        res.send(`
            <h1>Thank you for your submission, ${name}!</h1>
            <a href="/">Go back to the home page</a>
        `);
    } catch (error) {
        console.error("Error saving to the database:", error.message);
        res.status(500).send(`
            <h1>Something went wrong. Please try again.</h1>
            <p>${error.message}</p>
        `);
    }
});
Handles POST requests from the contact form.

Retrieves form data from req.body.

Saves data to MongoDB.

Sends a thank-you response on success.

If an error occurs, it sends an error message.
